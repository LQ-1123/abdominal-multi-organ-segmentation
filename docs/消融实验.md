# AMOS22 fold0：预处理与后处理消融

使用交接的 `fold0_val.zip` 和 V2 的 `outputs_v2/fold0/best.pth`。脚本直接从压缩包读取成对的 CT 与标注，不需要解压整包，也不依赖训练用的病例划分代码。以交接包内的病例名单作为 fold0；不要对这个子集重新分折，也不要用五折集成模型评估它。

## 实测结论

**后处理（59 例 CT）：** 建议保持现有的连通域清理。平均 Dice 从 0.8214 到 0.8229，而每例平均连通域数从 172.1 降到 19.2（约少 89%）。再加开闭运算，HD95 从 23.80 mm 降到 21.18 mm，但 Dice 降到 0.8198，右肾上腺相对不处理组下降 2.77 个百分点，不适合默认给所有器官启用。

**预处理（12 例 CT）：** 建议保留原输入处理。无额外预处理的平均 Dice 为 0.8041，高斯滤波为 0.7939（−1.02 个百分点），CLAHE 为 0.7809（−2.31 个百分点）。结论针对同一已训练模型的推理对照。

原始数字、逐病例表和切片对比图见 [`outputs/ablation_fold0/`](../outputs/ablation_fold0/)。

## 运行

在能使用 PyTorch、MONAI、NumPy、SciPy、scikit-image、Matplotlib 的环境中，从项目根目录执行：

```powershell
.\.venv\Scripts\python.exe scripts/run_ablations.py `
  --archive 'F:\BaiduNetdiskDownload\fold0_val.zip' `
  --pre-cases 12 --out outputs/ablation_fold0_rerun
```

默认跑两项实验。可加 `--study postprocess` 或 `--study preprocess` 单独运行；调试时用 `--max-cases 2` 和单独的输出目录。正式运行用空目录，避免不同实验的结果混在一起。

## 对照条件

- **病例：** 按 [AMOS22 官方数据包](https://zenodo.org/records/7155725) 内 `readme.md`，只取编号小于 500 的 CT，不把 MRI 当成 HU 图像。交接包共 72 对，符合 CT 条件 59 对，且没有恰好编号 0500 的病例。后处理用包内全部 CT；预处理从相同病例池按编号排序后等距取样，名单写进 `run.json`。
- **固定条件：** 1.5 mm 等向缓存，V2 fold0 单模型，112³ 滑窗、50% 重叠、高斯融合、窗口批量 1。CUDA 模型前向使用自动混合精度，在 CPU 拼接；常规输入窗为 [−150, 250] HU，线性映射到 [0, 1]。
- **后处理：** 同一预测比较不处理、仅用现有连通域清理（6 邻域，保留不小于最大块 2% 且不小于 30 体素的块，全部低于阈值时保留最大块），以及逐器官 3D 开运算→闭运算→同款连通域清理。开闭使用中心加六个轴向邻居的一体素结构元；不覆盖原本属于其他器官的体素，多个器官同时填补的位置留作背景。
- **预处理：** 比较无额外处理、窗限前的 3D 高斯滤波（σ = 1.0 mm）、窗限后的逐轴位切片 CLAHE（64×64 体素网格块，`clip_limit=0.01`）。三组都用同一权重、原始 argmax，无额外后处理。这里测的是**直接加到已训练模型的推理端**的效果。

## 怎么读结果

| 文件 | 内容 |
|---|---|
| `run.json` | 两项实验的病例名单、实际完成名单和推理设置 |
| `postprocess_summary.csv`、`preprocess_summary.csv` | 各方法整体和分器官汇总；`delta_dice_pp` 是相对未处理组的 Dice 百分点差 |
| `*_per_case.csv` | 逐病例、逐器官数据，可复核汇总值 |
| `*_slices.png` | 同一病例、同一层面；上排输入，下排预测叠加 |

Dice 先对每个器官的有标注病例取平均，再对器官取等权平均。真值有而预测没有时 Dice 记 0；真值没有时不计 Dice。HD95 用两方向表面距离的第 95 百分位中较大者（mm），只在预测与真值都非空时计算，比较时同时看 `hd95_n` 和 `missed_organs`。汇总行的连通域数是每例所有前景器官的连通域总数再取平均，包含真值缺失类别里的假阳性块。

输出会随病例更新。用 `completed_case_ids` 对照两项计划名单，区分中间结果和完整结果。这里的 CT 子集结果与历史五折 mDice 的病例范围和推理配置不同，不直接作差。
