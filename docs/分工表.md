## 二、工作明细

### 1. 选题与系统方案设计（孙钰林）

- 确定选题：腹部 CT 多器官分割（图像分割方向，AMOS22 数据集，15 器官）。
- 完成系统总体设计：「输入 3D、计算 3D、呈现 2D」架构，输出双通道（网页查看器 + NIfTI/metrics）。
- 数据集选型论证：MSD Spleen（链路验证）、AMOS22（主实验）、TotalSegmentator（备选）；BTCV 因域名不可达淘汰。
- 制定里程碑（M0-M6）与风险登记表。
- 产出：`docs/设计文档.md`（可直接作为报告「系统设计」章节底稿）、`README.md`。

### 2. 环境搭建与硬件适配（孙钰林）

- Python 3.11 虚拟环境 + PyTorch 2.10 (cu128) + MONAI 全套医学影像环境。
- 解决 RTX 5080（Blackwell, sm_120）无可用 kernel 的兼容问题（强制 cu128，3D 卷积实测通过）。
- 解决国内网络限速：aria2 16 线程下载脚本、pip 清华镜像，实测将 PyTorch 下载从 627 KB/s 提到 24-47 MB/s。
- 产出：`scripts/setup_env.ps1`、`scripts/check_env.py`、`requirements.txt`、`scripts/bootstrap.ps1`。

### 3. 数据集调研、下载与预处理（孙钰林）

- AMOS22 主数据集下载（200 例 CT + 标注，22.6 GB），断点续传。
- 预处理管线（`scripts/build_cache.py`）：
  - 抗锯齿重采样到 1.5mm 各向同性（原层厚 5mm，为层内分辨率约 9 倍）；
  - 影像线性插值、标签最近邻插值（避免标签线性插值产生不存在的类别值）；
  - HU 裁剪到 [-1024, 3071]；转 `.npy` 内存映射缓存，训练时按 patch 随机读取，不必载入整卷。
- 解决 SimpleITK 在 Windows 中文路径下无法读图的兼容问题（改用 nibabel 读入再转换）。

### 4. 数据集与训练数据管线（孙钰林）

- `src/data/amos_dataset.py`：
  - **按病例**做确定性 5 折划分（严格防止同一病例的 patch 泄漏到验证集）；
  - 前景过采样（fg_ratio 控制以器官为中心取 patch 的概率）；
  - 随机裁剪、三轴随机翻转；
  - V2 新增：亮度扰动（±10%）、偏移扰动、随机 Gamma（0.7-1.4）增强。

### 5. 3D U-Net 模型实现（孙钰林）

- `src/models/unet3d.py`：纯 PyTorch 实现（不依赖 MONAI，便于移植与答辩讲解）。
- 输出通道数可配置（单器官 2 / 8 器官 9 / 15 器官 16），为多器官任务和迁移学习预留。
- 深监督（辅助输出 0.5/0.25/0.125/0.0625 加权）、InstanceNorm3d（小 batch 下比 BN 稳定）。

### 6. 损失函数（孙钰林）

- `src/train/losses.py`：**缺失类别屏蔽的 DiceCE 损失**——AMOS 各病例器官不齐全，未出现的器官不参与损失统计，避免虚假拉低训练信号。

### 7. 5 折交叉验证训练系统（孙钰林）

- `src/train/train_amos.py`：128³ patch、AMP 混合精度、断点续训、CSV 逐 epoch 日志；
- 每 epoch 固定 patch 快速验证 + 每 fold 结束滑窗全卷评估（分器官 Dice）。

### 8. 两轮模型迭代（孙钰林）

| 版本 | 配置 | 5 折平均 mDice | 备注 |
|---|---|---|---|
| V1（`outputs/`） | 100 epoch | **0.7665 ± 0.012** | 基线 |
| V2（`outputs_v2/`） | 强度扰动 + Gamma 增强，120 epoch | **0.8056 ± 0.018** | **+0.0391** |

- 分器官结果（V2）：肝脏 0.944、脾脏 0.923、左/右肾 0.905/0.904；最难器官为肾上腺（0.66-0.67）。
- 对比表：`outputs/cv_compare.csv`；逐折逐器官明细：`outputs*/summary.json`。

### 9. 推理、后处理与阈值调优（孙钰林）

- `src/infer/predictor.py`：滑窗推理 + 高斯权重融合，支持 patch/overlap 配置。
- `src/infer/postprocess.py`：**连通域相对阈值清理**——保留体积 ≥ max(最大块×2%, 30 体素) 的连通域，解决肝脏 181 个、脾脏 41 个碎块问题，同时不误删十二指肠等天然多段结构。
- `scripts/tune_inference.py`：分器官概率阈值调优，全局 Dice 0.824（`outputs/tune_inference.json`）。

### 10. 评估汇总与报告图表（孙钰林）

- `scripts/summarize_cv.py`：5 折结果汇总 + V1/V2 自动对比表。
- `scripts/make_report_figs.py`：训练曲线、分器官 Dice 柱状图、折间分布、提升幅度共 4 张报告图（`outputs/figs/`）。

### 11. DICOM 摄取模块（孙钰林）

- `src/dicom_ingest/core.py`：序列选择（SeriesInstanceUID 分组）、HU 转换（RescaleSlope/Intercept）、按 ImagePositionPatient 法向投影排层序、方向矩阵归一化、各向异性重采样五步完整实现。

### 12. Web 演示系统（孙钰林）

- 后端 `web/backend/app.py`（FastAPI）：DICOM zip/NIfTI 上传、病例元信息、按层渲染 PNG（带缓存）、结果导出。
- 前端滚动查看器：上传 → 逐层滚动查看彩色分割叠加。
- 已积累 28 个演示病例（`outputs/web_cases/`）。

### 13. 逐层渲染与 3D 渲染（孙钰林）

- `src/render/slice_renderer.py`：逐层 PNG 渲染，支持窗宽窗位（腹部 WL=40/WW=400）、轮廓/填充模式（轮廓用形态学腐蚀求边界）。
- `scripts/render_3d.py`：marching cubes 表面提取 + 离屏渲染，多器官 3D 展示图（`outputs/demo/`）。

### 14. RL 边界精修（探索，孙钰林）

- `src/rl/refine.py`、`scripts/train_rl.py`、`scripts/rl_headroom.py`：PPO 逐层边界精修 Agent（状态 = 局部 patch + 符号距离场，动作 = 边界点位移，奖励 = ΔDice + 边界改善 − 曲率惩罚）。
- **诚实记录**：当前评估（`outputs/rl_eval.json`）显示胰腺、十二指肠、肾上腺上 before/after Dice 完全相同，即 RL 暂无增益；已预设「负结果叙事 + 消融分析」的处理方案（见任务书 T7）。

### 15. 演示数据生成器（孙钰林）

- `scripts/gen_demo_dicom.py`、`scripts/nifti_to_dicom.py`：NIfTI → DICOM 序列生成，保证答辩演示数据可控、不依赖网络。

### 16. 项目文档（孙钰林）

- `README.md`（项目说明、进度表、网络环境处理）与 `docs/设计文档.md`（完整设计决策与依据）。
