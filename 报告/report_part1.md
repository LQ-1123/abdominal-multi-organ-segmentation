# 1 选题背景与意义

腹部 CT 是肝、肾、胰腺等脏器疾病最常用的检查手段之一。放疗计划、手术规划和器官体积随访都要先把器官从影像里勾画出来，人工逐层勾画一例腹部 CT 的十几个器官往往要一到数小时，而且不同医生之间的勾画差异明显。自动多器官分割可以把这部分工作降到分钟级，是医学图像分析中需求很明确的一个方向。

本课题属于图像分割方向，任务是对三维腹部 CT 做体素级的 15 类器官分割。这个任务有几处难点：一是器官大小悬殊，肝脏体积可达一千多毫升，肾上腺只有几毫升；二是胰腺、十二指肠、肾上腺等器官与周围软组织的 CT 值非常接近，在灰度上几乎看不出边界；三是数据来自不同医院、不同扫描仪，层厚在 1.25～5 mm 之间。

目前这一任务的主流做法是全卷积网络。U-Net[2] 用编码器—解码器结构加跳跃连接，在医学图像分割上效果突出；3D U-Net[3] 和 V-Net[5] 把它扩展到三维体积；nnU-Net[4] 进一步按数据集自动配置预处理、网络和训练参数，在多个公开评测中名列前茅。MSD[10]、TotalSegmentator[9] 和 AMOS[1] 等公开数据集也让方法之间可以在同一基准上比较。这些方法的平均精度已经不错，但在小器官、碎块和边界上仍有明显缺陷，本文的实验也印证了这一点。

课程讲授的灰度变换、空间域与频率域滤波、直方图均衡化、边缘检测和形态学处理[6]，正好对应这些问题中的若干环节：窗宽窗位是分段线性灰度变换，重采样是图像内插，平滑滤波和 CLAHE 作用于输入噪声与对比度，连通域和开闭运算作用于输出的形状。本文以三维 U-Net 为分割主干，把这些课本方法放到预处理和后处理环节，用对照实验逐项测量它们对分割结果的实际影响，并据此决定最终系统保留哪些处理。

# 2 数据集与数据特性分析

## 2.1 数据集来源

实验采用 AMOS22 腹部多器官分割数据集[1]。该数据集来自深圳两家医院的多中心临床数据，共 500 例 CT 与 100 例 MRI，标注了脾脏、左右肾、胆囊、食管、肝脏、胃、主动脉、下腔静脉、胰腺、左右肾上腺、十二指肠、膀胱、前列腺/子宫共 15 个器官。数据集通过 Zenodo 公开下载（记录号 7155725），采用 CC BY 4.0 协议，本文仅将其用于课程作业。公开包中带标注的是训练集与验证集，共 360 例（CT 300 例、MRI 60 例），测试集不公开标注。

## 2.2 数据整理与样本划分

原始数据为 NIfTI 格式。整理步骤如下：

（1）读取与方向统一。用 nibabel 读入体积并转为 Z、Y、X 顺序，同时从仿射矩阵恢复体素间距、原点和方向。没有直接用 SimpleITK 读文件，是因为它在 Windows 下按 ANSI 编码处理路径，项目目录含中文时会读取失败。

（2）重采样到 1.5 mm 各向同性。原始数据层内间距约 0.45～1.07 mm，层厚多为 5 mm，体素在 Z 方向被拉长了数倍。三维卷积核在三个方向上等长，不先统一间距，网络在 Z 方向看到的解剖范围比 X、Y 方向大好几倍。影像用三线性插值，标签用最近邻插值；标签若用线性插值，相邻两个器官的编号会被平均成第三个不存在的编号。这一步对应课本中的图像内插。

（3）CT 值截断与缓存。影像截断到 [−1024, 3071] HU 后以 int16 保存，标签以 uint8 保存，都存成可内存映射的 .npy 文件，训练时按 patch 读取，不必把整卷载入内存。

（4）按病例划分五折。每个病例只出现在一折中，同一病人的 patch 不会同时进入训练集和验证集。第 0 折验证集有 72 例，其中 CT 59 例。本文所有课本方法的对照实验都用这 59 例 CT：CT 值有明确的物理含义，窗宽窗位和滤波参数可以按 HU 设定，MRI 没有这种对应关系。

## 2.3 数据特性

!fig outputs/report_figs/fig_data.png | 图 1 AMOS22 CT 数据特性：（a）原始层厚分布；（b）各器官体积（对数坐标）；（c）各器官 CT 值分布，灰色带为模型输入窗 [−150, 250] HU

对全部 300 例带标注 CT 的统计见图 1，有三点直接影响方法设计：

第一，体素严重各向异性。原始层厚中位数 5.0 mm，层内间距中位数 0.68 mm，这是先做各向同性重采样的原因。

第二，类别极不平衡。前景器官只占体积的 3.6%，其余都是背景；器官之间体积中位数相差约 400 倍（肝脏 1222 mL，右肾上腺 3.1 mL）。按体素平均的交叉熵会被背景和大器官主导，因此训练采用 Dice 与交叉熵组合的损失，评价时按器官分别计算后再平均。

第三，软组织器官的 CT 值高度重叠。图 1(c) 中胰腺、十二指肠、肾上腺、脾脏、肝脏的中位 CT 值都落在 20～65 HU 之间，彼此的分布大面积重合。仅凭灰度阈值无法区分这些器官，必须依靠形状和位置等上下文信息，这也是选用深度网络做主干的理由。同时，所有器官的 CT 值都集中在 [−150, 250] HU 内，把这一段线性拉伸到 [0, 1] 可以在不丢失器官信息的前提下把对比度用足。

# 3 方法

## 3.1 总体流程

系统流程为：读入 CT（DICOM 或 NIfTI）→ 统一方向并重采样到 1.5 mm → 窗宽窗位灰度变换 →（可选）课本预处理 → 三维 U-Net 滑窗推理 → 课本后处理 → 逐层渲染与三维显示。其中预处理和后处理各有几种候选方法，是否保留由第 4 章的对照实验决定。

## 3.2 基于课本知识的预处理

### 3.2.1 窗宽窗位：分段线性灰度变换

CT 值范围约 −1024～3071 HU，而腹部器官集中在 −150～250 HU。若把整个范围线性映射到 [0, 1]，软组织只占很窄的一段灰度，彼此几乎没有对比。本文采用课本中的分段线性灰度变换（对比度拉伸）：

!eq s = 0, r < −150；s = (r + 150) / 400, −150 ≤ r ≤ 250；s = 1, r > 250

其中 r 为 CT 值，s 为网络输入。这相当于放射科常用的腹部软组织窗（窗位 50 HU、窗宽 400 HU）。这一变换是整个系统的固定环节，所有对照组都在此基础上比较。

### 3.2.2 空间域平滑：高斯滤波与中值滤波

CT 图像含有量子噪声，低剂量扫描时尤其明显。高斯滤波是线性低通滤波，用高斯核与图像卷积：

!eq G(x, y, z) = exp(−(x² + y² + z²) / (2σ²)) / ((2π)^(3/2) σ³)

本文在窗限之前、HU 空间内做三维高斯滤波，σ 取 1.0 mm（约 0.67 个体素），只抑制体素级噪声，不明显模糊器官边界。中值滤波是统计排序滤波，用 3×3×3 邻域的中值替换中心体素，对孤立的脉冲噪声效果好，且比均值类滤波更能保留阶跃边缘。

### 3.2.3 频率域滤波：Butterworth 低通

为与空间域方法对照，本文还在频率域做了平滑。对整卷做三维快速傅里叶变换，乘以 Butterworth 低通传递函数后再逆变换：

!eq H(u, v, w) = 1 / [1 + (D(u, v, w) / D₀)^(2n)]

D 为频率点到原点的距离，单位为周期/毫米。1.5 mm 采样对应的奈奎斯特频率约为 0.33 周期/毫米，本文取截止频率 D₀ = 0.2 周期/毫米、阶数 n = 2。选二阶 Butterworth 而不选理想低通，是因为理想低通在空间域会产生明显的振铃，在器官边缘形成假的亮暗条纹；二阶 Butterworth 的过渡带较平缓，振铃可以忽略。变换前先减去体积均值，避免直流分量受周期延拓边界的影响。

### 3.2.4 图像增强：限制对比度自适应直方图均衡（CLAHE）

全局直方图均衡按整幅图的累积分布重新分配灰度，腹部 CT 中大面积的背景和脂肪会主导映射结果。CLAHE[8] 把图像分成小块分别均衡，并对每块直方图设上限，超出部分均匀分摊，从而限制噪声被放大。本文在窗限之后逐个轴位切片做 CLAHE，块大小 64×64 像素（约 96 mm），截断系数 0.01。

### 3.2.5 推理端对照与训练端对照

上述四种方法都可以只加在推理端，即用原模型直接处理经过滤波或增强的输入。但原模型训练时没有见过这类输入，推理端的变化同时包含"方法本身的作用"和"输入分布偏移的代价"两部分。为把两者分开，本文另做了训练端对照：从同一个已训练好的模型出发，每组用对应预处理后的数据继续训练相同轮数，再在同样预处理后的验证集上评估。各组的随机种子、学习率、patch 采样位置和数据增强完全相同，唯一的差别是输入预处理。

## 3.3 三维 U-Net 分割模型

### 3.3.1 网络结构

主干采用三维 U-Net[2,3]，用纯 PyTorch 实现，共约 22.6 M 参数。编码器 5 个层级，通道数依次为 32、64、128、256、512，每级两个 3×3×3 卷积，每个卷积后接 InstanceNorm 和 LeakyReLU（负斜率 0.01），级间用 2×2×2 最大池化下采样；解码器用步长 2 的转置卷积上采样，再与编码器同级特征拼接后卷积。输出 16 个通道，对应背景和 15 个器官。批大小只有 3，BatchNorm 的批统计量不稳定，因此改用 InstanceNorm。训练时在解码器最后一层特征上另接 4 个 1×1×1 辅助输出头，特征依次平均池化，得到原尺度、1/2、1/4、1/8 尺度的辅助预测，与最近邻下采样后的标签计算损失，权重依次为 0.5、0.25、0.125、0.0625，主输出权重为 1。推理时只用主输出。

### 3.3.2 损失函数

损失为 Dice 损失与交叉熵之和。AMOS22 中并非每个病例都有全部 15 个器官（例如前列腺/子宫因性别而异，胆囊可能已切除），一个随机 patch 里出现的器官更少。若对缺失器官也计算 Dice 损失，网络会因为"预测为空"而得到满分或零分，训练信号失真。本文在每个 patch 中只对实际出现的类别计算 Dice 损失，这里称为缺失类别屏蔽的 DiceCE 损失。

### 3.3.3 训练设置

训练用 112³ 体素的 patch，批大小 3，每个病例每轮取 3 个 patch；取 patch 时按一定比例把中心放在器官体素上（前景过采样），缓解前景过少的问题。数据增强包括三个轴向的随机翻转、±10% 的亮度缩放与亮度偏移，以及 0.7～1.4 的随机 Gamma 变换。Gamma 变换就是课本中的幂律灰度变换 s = c·r^γ，这里用来模拟不同扫描条件下的对比度差异。优化器为 AdamW，初始学习率 1×10⁻⁴，权重衰减 1×10⁻⁵，余弦退火 120 轮，混合精度训练，按每轮验证 patch 的 Dice 保存最佳权重。推理时用 MONAI[11] 的滑窗推理，窗口 112³，相邻窗口重叠 50%，重叠区按高斯权重融合，减轻窗口边缘处的拼接痕迹。

## 3.4 基于课本知识的后处理

### 3.4.1 连通域清理

三维网络逐体素做 argmax，输出中会散布大量孤立的小块。例如第 0 折验证集上，未经处理的预测平均每例有 172 个连通域，而 15 个器官在解剖上基本都是单一连通结构。本文用 6 邻域标记每个器官的连通分量，保留体积不小于"最大块的 2%"且不小于 30 个体素的分量，其余置为背景。没有简单地只留最大块，是因为十二指肠是 C 形管道，预测时可能断成几段，最大块有时只占一半左右，只留最大块会删掉真实结构。

### 3.4.2 形态学开运算与闭运算

形态学处理[6,14]中，开运算是先腐蚀后膨胀，能去掉比结构元小的毛刺和细桥；闭运算是先膨胀后腐蚀，能填平比结构元小的孔洞和裂缝：

!eq A ∘ B = (A ⊖ B) ⊕ B，A • B = (A ⊕ B) ⊖ B

本文对每个器官的二值掩膜依次做三维开运算和闭运算，结构元为中心加 6 个轴向邻居（半径 1 个体素，1.5 mm），然后再做连通域清理。闭运算填补出的体素只允许占用原来的背景，不覆盖其他器官；两个器官同时要填同一个体素时，该体素保留为背景。

### 3.4.3 选择性开闭运算

开运算会删掉宽度小于结构元直径（3 个体素，4.5 mm）的结构。肾上腺的肢体只有几毫米厚，食管在部分层面也很细，对这些器官做开运算会直接削掉真实组织。为此本文设计了按器官选择的开闭运算：把第 0 折的 59 例 CT 按编号排序后交替分成两半，在前一半（开发集，30 例）上比较每个器官做与不做开闭运算的 Dice，只对 Dice 不下降的器官启用开闭运算；器官名单定下来以后，在另一半（测试集，29 例）上检验效果。名单的确定不使用测试集的任何信息。

## 3.5 评价指标

（1）Dice 系数[13]衡量预测与真值的重叠程度：Dice = 2|P∩G| / (|P| + |G|)。对每个器官先在有该器官真值的病例上取平均，再对 15 个器官等权平均，得到 mDice。真值有而预测完全没有时记为 0。

（2）95% Hausdorff 距离（HD95）[12]衡量边界的最大偏差：分别计算预测表面到真值表面、真值表面到预测表面的距离，各取第 95 百分位数，再取两者较大值，单位 mm。取第 95 百分位数而不取最大值，是为了不让个别离群体素决定结果。离主体很远的假阳性碎块会显著拉高 HD95，因此它对后处理比 Dice 敏感。

（3）连通域数：每例所有器官的连通分量总数，直接反映预测的碎片化程度。

（4）显著性检验：每例先对器官取平均得到一个病例级分数，两种方法在同一批病例上配对，用 Wilcoxon 符号秩检验[16]判断差异是否显著，并用 10000 次 bootstrap 重采样给出均值差的 95% 置信区间。
